# Stock Pet for Windows

Windows x64 免安装版。解压完整目录后运行 `StockPet.exe`，不要只把 EXE 单独移出目录。

## 功能

- A 股、港股、美股真实当日分时曲线，股票数量不设上限
- 透明无边框悬浮、拖拽、整体缩放、始终置顶和鼠标穿透
- 股票较多时桌宠和搜索结果均可上下滚动
- 默认隐藏股票代码与市场，仅显示更醒目的名称；可随时开启
- 曲线所占的横向宽度和字体大小可独立调整，名称、价格和涨跌幅统一跟随文字不透明度
- A/H 红涨绿跌，美股绿涨红跌
- 双击桌宠打开设置，系统托盘可解除鼠标穿透
- 可自定义全局快捷键显示或隐藏桌宠
- 牛熊提醒支持昨收涨跌幅或逐股目标价；可实时刷新现价并一键生成上下目标
- 提醒可关闭、可调不透明度，并带牛 A / 熊 A 提示音
- 最新价、涨跌幅和提醒最快可 1 秒批量刷新；分时曲线独立按 15 秒或更慢频率更新
- 可通过两条独立路线检查新版本，下载并校验对应中文 Windows 包，不会静默替换应用
- 腾讯秒级报价与分时为主、东方财富备用；失败自动退避并保留最后一次成功数据

## 系统

- Windows 10 64 位或更高版本
- Intel 或 AMD x64 处理器

此交付物未使用商业代码签名证书。Windows SmartScreen 可能在首次启动时显示提醒。
